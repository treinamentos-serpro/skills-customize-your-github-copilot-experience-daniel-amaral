
# 📘 Tarefa: Jogo da Forca

## 🎯 Objective

Desenvolva um jogo da Forca em Python para praticar manipulação de strings, estruturas de repetição, condicionais e entrada de dados. O jogador deve descobrir uma palavra escolhida aleatoriamente antes de esgotar as tentativas.

## 📝 Tasks

### 🛠️ Selecionar a Palavra e Exibir o Progresso

#### Descrição
Implemente a seleção da palavra secreta e a exibição do progresso enquanto o jogador envia palpites de letras.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra da lista predefinida
- Solicitar um palpite de letra por vez
- Exibir a palavra com as letras acertadas reveladas e as demais ocultas, por exemplo, `_ _ _`

### 🛠️ Controlar as Tentativas e Encerrar o Jogo

#### Descrição
Controle as tentativas incorretas e finalize a partida quando o jogador descobrir a palavra ou atingir o limite de erros.

#### Requisitos
O programa concluído deve:

- Definir e atualizar o número de tentativas incorretas restantes
- Encerrar o jogo quando todas as letras da palavra forem descobertas ou não houver mais tentativas
- Exibir uma mensagem indicando vitória ou derrota
